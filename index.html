Instinct AI: group tally agent

Nov 2026 · GitHub

Side project · Million Pint Challenge: a community counting toward 1,000,000 pints by 2036, starting with 12 friends and aiming for 1,000+ members

  • Replaced manual counting with an agent. Members post a photo and a description of each drink. Every Monday a Claude agent reads the week's messages, applies the group's rules (e.g. non-alcoholic drinks count half) and calculates the running total.
  • Built to scale. Manual counting works for 12 people and breaks at 1,000. The agent is what lets the group grow without someone tallying by hand.
  • Chose a read-only design to manage platform risk. WhatsApp can ban accounts that run automated messaging. The agent only reads the group through a linked device and sends the tally to me privately, never posting itself. I traded full automation for not risking my own WhatsApp account.
